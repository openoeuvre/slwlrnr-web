# SLWLRNR — Activity card concepts

Twenty-five concepts drafted for the `/learn` mock-up. Not final copy — these
are idea seeds, each tied to one of the natural systems behind the work.

| # | Card title | Description |
| --- | --- | --- |
| 01 | Two Inks, One Sheet | Watch two liquids compete for the same surface and settle into a pattern neither one chose. |
| 02 | Finding the Branch Point | Trace a real branching system and discover where it decides to split. |
| 03 | The Sunflower Count | Count the spirals in a seed head and find the numbers hiding in them. |
| 04 | Salt on a Drum | Make a vibrating surface show you where it is standing still. |
| 05 | Nearest Neighbour | Divide a page so that every point belongs to whichever dot is closest. |
| 06 | Dye in Moving Water | Learn to read a flow by what it does to a colour dropped into it. |
| 07 | Growing Toward Food | Set up a foraging network and watch it abandon its own failed routes. |
| 08 | Bands of Time | Build a layered deposit and read your own record back out of it. |
| 09 | Two Sources, One Image | Combine two of your own photographs by hand before ever using the tool. |
| 10 | Spikes and Spacing | Find out what sets the distance between peaks in a driven surface. |
| 11 | Reading a Crack | Work out the order in which a cracked surface actually broke. |
| 12 | The Angle That Never Repeats | Test why 137.5° packs a surface better than any simpler angle. |
| 13 | Slowing a Reaction Down | Change one rate and watch spots turn into stripes. |
| 14 | Streaklines | Build a flow with an obstacle in it and record what forms behind. |
| 15 | Same Rule, Four Scales | Draw one branching rule at four magnifications and compare. |
| 16 | What the Surface Kept | Blend two images and account for exactly what survived from each. |
| 17 | Nodal Lines by Hand | Draw standing waves and find where they cancel. |
| 18 | Cost of a Connection | Design a network three ways and work out which one a forager would build. |
| 19 | Unconformity | Build a layered record with a gap in it and see if the gap reads. |
| 20 | Seeds and Density | Change only seed density and watch the character of a pattern shift. |
| 21 | Choosing the Dominant Source | Run the same pair of images at five weightings and find where it turns. |
| 22 | Instability Threshold | Find the exact moment a smooth surface gives way to structure. |
| 23 | Deliberate Interruption | Use an obstacle as a compositional decision rather than an accident. |
| 24 | One System, Two Sources | Hold the system constant and vary only the inputs, five times over. |
| 25 | Building a Series | Assemble six related works and decide what actually makes them a set. |
